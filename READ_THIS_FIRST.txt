=====================================================================
 IMPORTANT - HOW THE QUIZ BROKE, SO IT DOESN'T HAPPEN AGAIN
=====================================================================

Someone renamed super-mega-quiz.html using GitHub's website. GitHub's
web editor cannot handle files bigger than a few megabytes - it
replaced the whole 3.7 MB file with an empty stub, and gave no error.

So: NEVER use the pencil (edit) or rename option on GitHub's website
for a big file. Uploading via "Add file > Upload files" is safe.
Renaming on your own computer and pushing with git is safe.
