📖 Read the symbol key

  1. A · Type I

    Allergic: IgE and mast cells.

  2. C · Type II

    “Cytotoxic”: antibody targets cells or receptors.

  3. I · Type III

    Immune complexes deposit in tissues.

  4. D · Type IV

    Delayed, T-cell mediated response.

One thing to keep

Type II can change receptor function without killing the cell. Type IV is not antibody mediated.

🧠 Try it from memory

Which hypersensitivity type is T-cell mediated?

Reveal the answer

Type IV. Contact dermatitis and the tuberculin skin-test response are common course examples.
