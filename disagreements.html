How this was found. Every module page’s high-yield card, ATI card, exam traps and notes were pulled out and read against each other, one page at a time, looking only for a fact stated twice with different values. Things that merely looked like conflicts — onset versus peak, two named grading systems, a fixed value sitting inside a stated range — were checked and set aside.
