# Bedside test illustrations

Created with OpenAI image generation for the bedside test study cards. These are illustrative teaching scenes, not clinical photographs or calibrated examination tools.

The generation brief requested clear clinician/patient positioning, visible equipment and hand placement, short labels, and distinct panels for each test. The sheets were reviewed and revised for the Babinski stroke path, fluid-wave midline hand, CVA percussion, bladder probe placement, GCS instruction, and Braden domains.

The WebP files preserve the generated dimensions. CSS clips individual panels using the pixel rectangles in `manifest.json`; the same rectangle is used in the enlarged dialog. A separate Babinski illustration replaces that sheet panel. Existing Weber/Rinne, Leopold, and fundal-height infographics are reused from `../infographics/`.

Captions and alt text live in the page and manifest. References consulted for procedure positioning include the Merck Manual neurological examination and Stanford Medicine 25 examination guides:

- https://www.merckmanuals.com/professional/neurologic-disorders/neurologic-examination/how-to-assess-reflexes
- https://med.stanford.edu/stanfordmedicine25/exam-guides-.html

Illustrations support the written steps and supervised clinical training; they are not standalone procedural instructions. Existing clinical card text was not revised in this illustration update.
