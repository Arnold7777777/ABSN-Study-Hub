=====================================================================
 THE ONE MISTAKE - AND HOW TO AVOID IT
=====================================================================

You have now uploaded the ZIP FILES to GitHub twice instead of what is
inside them. Your repo currently contains six .zip files sitting there
doing nothing. GitHub cannot open a zip - it just stores it.

This is a classic Windows trap, not something you did wrong:
when you double-click a .zip, Windows SHOWS you the contents in a
window that looks exactly like a normal folder. But it is still inside
the zip. Dragging from that window usually fails or drags the zip.

YOU MUST EXTRACT FIRST. Here is how, exactly:

  1. Find this file in your Downloads:  ABSN_FINAL.zip
  2. RIGHT-CLICK it
  3. Choose "Extract All..."
  4. A box appears. Click "Extract".
  5. A NEW window opens showing a real folder called ABSN_FINAL

HOW TO TELL YOU DID IT RIGHT:
  Look at the address bar at the top of that window.
    RIGHT:  C:\Users\carol\Downloads\ABSN_FINAL
    WRONG:  C:\Users\carol\Downloads\ABSN_FINAL.zip
  If you see ".zip" in the path, you are still inside the zip.
  Go back and do step 2.


=====================================================================
 THEN UPLOAD
=====================================================================

  6. Go to  https://github.com/arnold7777777/ABSN-Study-Hub
  7. Click "Add file"  >  "Upload files"
  8. From the extracted ABSN_FINAL folder, drag in these FOUR items:

         more                  (folder)
         neuro                 (folder)
         resp                  (folder)
         infographics.html     (file)

     Do NOT drag START_HERE.txt.
     Do NOT open the folders - drag the folders themselves.

  9. Wait until GitHub finishes listing all 66 files. This takes a
     moment. Do not click Commit until the list stops growing.
 10. Click "Commit changes".


=====================================================================

 11. Open https://arnold7777777.github.io/ABSN-Study-Hub/infographics.html

 13. Scroll to "Skin & wounds". The Pressure Injuries card should show

     box. If you still see the orange box, the upload did not take.
